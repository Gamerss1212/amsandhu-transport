# Research notes

One file per strategy family, written by `/validate-strategy`. Each note has, in order:

1. Hypothesis and economic reason
2. Data used and its limits
3. Every variant tried and the trial count
4. The A44 table, the A39 findings and the 2x-cost result
5. Verdict (PASS or FAIL) and what evidence would change it

"No edge found" is a valid and useful result.
