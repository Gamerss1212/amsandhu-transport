TRADING AI - START HERE
=======================

1. Unzip TradingAI.zip anywhere you like (for example Documents\TradingAI).
   Keep START_TRADING_AI.exe and the _internal folder together.

2. Double-click START_TRADING_AI.exe

   - A small black window opens and says "Local server running at http://127.0.0.1:8000".
     Keep it open while you use the dashboard. Closing it stops everything safely.
   - Your web browser opens the dashboard by itself. If it does not, type
     http://127.0.0.1:8000 into the browser (the window shows the exact address).
   - Double-clicking again while it runs just opens the dashboard again.
   - Windows SmartScreen may warn about an unknown publisher the first time (the program is not code-signed).
     Click "More info" -> "Run anyway" only if you got this file from your own repository.

3. You start in PAPER mode. Paper = simulated money at real market prices. No real money moves.

WINDOWS 11 (and Windows 10)
---------------------------
- Needs 64-bit Windows 10 or 11. Nothing else to install: Python and everything else are inside the folder.
- Unzip first (right-click the zip -> Extract All...). Running the exe from inside the zip preview does not work.
  Use a normal folder such as Documents\TradingAI, not C:\Program Files (the program writes its data next to itself).
- "Windows protected your PC" (SmartScreen): click "More info" -> "Run anyway". It appears because the program is
  not code-signed. Only do this for a file you downloaded from your own repository.
- Smart App Control (only on some newly installed Windows 11 PCs) blocks unsigned programs completely, with no
  "Run anyway" button. Check it in Settings -> Privacy & security -> Windows Security -> App & browser control ->
  Smart App Control. If it is On, this program cannot start. Turning it off is a security trade-off and cannot be
  switched back on without reinstalling Windows, so decide carefully. A code-signing certificate (paid) would remove
  this problem; this version does not have one.
- If Windows Security (Defender) quarantines START_TRADING_AI.exe: programs packed like this one are sometimes
  flagged by mistake. Open Windows Security -> Protection history, check it is this file, and choose Allow only if
  you trust where it came from.
- The program only listens on 127.0.0.1 (this computer), so Windows Firewall does not need to be opened.

CHECK YOUR COMPUTER'S TEMPERATURE (THERMAL CHECK)
-------------------------------------------------
Double-click CHECK_COMPUTER_TEMPERATURE.bat in this folder (or press "Run thermal check" on the Master Agent page).
  - It runs every CPU core at full load for 5 minutes, with 1 minute idle before and 1 minute to cool down after.
  - Every 5 seconds it reads Windows' own sensors: temperature, whether Windows is slowing the CPU to cool it
    ("passive limit"), and the CPU's speed. It also measures how much work the CPU gets done, which falls if the
    CPU throttles - so problems show up even on PCs with no temperature sensor.
  - It stops by itself at 95 C. Press Ctrl+C to stop it at any time.
  - Result: PASS, PASS (no temperature sensor), WARNING (above 85 C, throttling, or the speed fell more than 30%),
    or FAIL (it reached 95 C). The report is saved in the thermal-reports folder.
  - Many desktop PCs do not report a temperature to Windows, and a Windows "thermal zone" is often the motherboard,
    not the CPU core. For the exact core temperature use a tool such as HWiNFO alongside it.
  - Full load is harder than anything this program does: its heaviest work (training) runs at most 2 research jobs at once. While
    the program runs it checks the temperature every 30 seconds and pauses training if the computer runs hot.

                    the system is trading or waiting), what the engine is doing beside the chart,

Master Agent        The master agent and its 100 trading agents A001-A100. "Network" shows every agent

                    market data). "Agent grid" lets you search and filter them. Click any agent to see
                    its role, its versions (with their test results), whether it may trade now and why,
                    its mistakes, and a "Run check" button that tests its decision without trading.
                    "Learning" shows every lesson, mistake and regression replay. "Support services

Brokers & Accounts  Your paper account, broker connections, Add Funds (opens your broker's own website),
                    what each broker supports, which markets are covered (including meme coins), live
                    readiness and arming, orders and fills, reconciliation.

THE ASSISTANT
-------------
The "Assistant" button (bottom left, on every page) answers questions from the system's real state:
"What are all the bots doing?", "Why are you not trading?", "How much did fees cost today?",
"Which strategies are under review?", "Explain my current exposure", "Show my broker connection".
You can ask about one bot by its market ("What is the bitcoin bot doing?") and then say "that bot"
("Pause that bot"). Say or type "pause new entries" and it does that. It refuses anything about real
money, going live or permissions: those stay on the pages, behind their own confirmations.
Tick "voice" to hear answers (British English voice if Windows has one) and "speak events" to have it
announce important events by itself. "vol" sets the loudness; "quiet" sets hours when only critical
events are spoken. Each announcement shows whether it was spoken, and the panel shows how long speech
took to start after the event. "Mic" lets you ask by voice where the browser supports it.
It uses no cloud AI.

THE STRATEGY CATALOG
--------------------
"Open catalog" on the AI Trading System page lists the 124 strategy templates and the 212-entry
research index from your specification, with their sources. Each template shows whether this
software can run it, and if not, why (a reason code such as PRODUCT_UNSUPPORTED for options).
"Your batches" shows your own Batch 01-03 results. You do not run tests yourself: the agents
test every template they can by themselves. CATALOG_BACKTEST_REPORT.md (next to this file) has
the results of testing them on real data.

IT RUNS BY ITSELF (THE MASTER AGENT)
------------------------------------
You do not need to set anything up. Opening the program is "Start System". The master agent is ON from
the first start and works in PAPER mode:

  1. It gives each of its 100 trading agents one market and a role, for example "large US stocks:
     breakouts" or "liquid crypto: trend". Each role has 3 candidate strategies, chosen from published
     research (STRATEGY_RESEARCH.md, next to this file).
  2. It trains every agent on that market's real price history. Settings are fitted on the older 60%,
     the best candidate is picked on the next 20%, and the newest 20% is kept back as an honest final
     test. A version may trade (paper only) only if it passes EVERY test.
  3. An agent with a passing version buys and sells by itself, without asking you trade by trade.
     The master can stop it at any time, and the risk limits check every order.
  4. Every week it retrains. A new version must first beat the old one on new prices ("shadow")
     before it replaces it. A version that loses more than planned is rolled back automatically.
  5. Every mistake (for example, an order the risk check refused) is recorded with its cause. The
     lesson becomes a safeguard for all 100 agents and is re-tested every hour.

MARKETS: since 1.7.0 the program trades only US stocks, crypto and meme coins. Forex, futures, options
and bonds were removed. ETFs and indices are used only as price references (never bought or sold).

DAY TRADING: trades open and close the same day. Stocks are closed 10 minutes before the market closes,
and a crypto or meme-coin trade is never held more than 24 hours. The
tests use exactly the same rules, so strategies that need to hold for days or months stay "research only".

IMPORTANT: when this version was built, none of the 100 agents' versions passed every test on real data
(AGENT_TRAINING_REPORT.md has every number). Until one does, the system opens NO trades. It watches
the markets, keeps retraining and stays in cash. This is the safety rule working, not a fault. Ask
the assistant "Why are you not trading?" at any time.

The two big buttons:
  Start System = master agent on + every agent's loop running (already done when the program opens)
  Stop         = every agent's loop stopped + master agent paused

To have it start whenever you turn on the computer, tick "Start automatically when Windows starts"
in the Master agent panel.

IF YOU WANT THE OLD VERSION BACK: see BACKUP_AND_RESTORE.md. The 1.4.1 download is kept, and 1.5.0 copies
your old database before changing it.

SAFETY
------
- PAUSE NEW ENTRIES stops new trades but lets bots close what they hold. Resume undoes it.
- FLATTEN ALL closes every paper position now (each one reports whether it really closed).
- EMERGENCY STOP (top right) stops every bot, cancels working orders and blocks new orders.
- Risk limits are checked on every order by fixed rules. No agent can raise them.
- Real-money trading stays OFF. It can only be armed on Brokers & Accounts with a verified live broker
  connection, every readiness check passing, your caps, and a typed confirmation. In this version no
  broker adapter has passed a live acceptance test yet, so live arming stays locked.
- Never give this program (or anyone) a key with withdrawal permission.

YOUR DATA
---------
Everything is stored next to the program in the "data" folder: database, market data, encrypted
credentials (Windows DPAPI, readable only by your Windows user), and a database backup in
data\backups each time you close the program.
Logs are in the "logs" folder. To move to a new computer, copy the whole folder (re-enter broker keys:
DPAPI-encrypted keys only open for the Windows user who saved them).

IF SOMETHING GOES WRONG
-----------------------
- "Already running" but no page: wait 10 seconds and double-click again.
- The page says the server is unreachable: the black window was closed. Start the program again.
- Port 8000 busy: the program picks the next free port and shows it in the black window.
- Send logs\trading-ai.log when asking for help (it never contains your keys).

Nothing in this program is financial advice. Backtests describe the past under stated assumptions.

Chrome and Claude Code (logged in). Full steps: JARVIS.md.

CAN $100 BECOME $300,000?
-------------------------
No software can promise that, and this one does not. $100 to $300,000 is 3,000 times the money. The 100 agents have not
passed their tests yet, so none is trading. Read CAN_100_DOLLARS_BECOME_300K.md for the maths and the measured results.
